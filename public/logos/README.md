# Logos

All files supplied by the project team, trimmed and resized for the web.

- `eu-esf.png`: EU emblem with "European Union, European Social Fund". Never redraw or recolour it.
- `eu-cofunded-fi.png`: EU emblem with "Euroopan unionin osarahoittama" (Finnish). Not used at the moment.
- `haaga-helia.png`, `oulu.png`, `lab.png`, `seamk.png`: partner logos.

To swap a logo, keep the same file name and update its width and height in `src/lib/nav.ts`.
The project image used on the home page and as the tab icon is `src/assets/aikaa-visual.jpg`.
